# وثيقة تسليم المشروع

## اسم المشروع

نظام اكتشاف الأسلحة مع إنذارات وتقارير يومية

## الموديل المعتمد

- `models/approved/weapon_detector_best.pt`

## الهيكلية العامة

1. الكاميرا ترسل البث.
2. Backend يستقبل البث ويشغل الموديل.
3. عند وجود كشف يتم إنشاء إنذار.
4. يتم حفظ الحدث وصورته.
5. Frontend يعرض البث والإنذارات والتقارير اليومية.

## مسؤوليات Backend

1. ربط الكاميرا مع النظام.
2. تشغيل الموديل المعتمد.
3. إنشاء الإنذارات.
4. حفظ الأحداث.
5. بناء API.
6. إنشاء تقرير يومي بسيط.

## مسؤوليات Frontend

1. بناء الصفحة الرئيسية.
2. بناء صفحة البث المباشر.
3. بناء صفحة الإنذارات.
4. بناء صفحة التقارير اليومية.
5. بناء صفحة الإعدادات.
6. ربط الواجهة مع API.
